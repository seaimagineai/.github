# 对照审查记录

2026-09-24，完成三轮源库对照及主对话独立检查。

1. **第一轮：源库盘点。** 子代理核对 FLAQ 实际首屏、语言栏、项目介绍和页脚；主对话保留这些阅读结构，以 SeaImagine 的三个真实项目适配正文。没有搬入不相关的 API 定位、联盟条款或项目数量。
2. **第二轮：初稿审查。** 子代理指出语言按钮“查看资料库”与切换语言的行为不符、中文缩写不利于初学者，以及项目用途标签缺少冒号。主对话接受三项意见，修改全部语言的按钮与标签，并修正简繁中文措辞。封面格式转换属于可选建议，本次保留已有图片。
3. **第三轮：修改后复查。** 子代理复核生成文件、语言结构及源库差异，未发现必须修改的问题。
4. **主对话独立检查。** 使用 GitHub Markdown API 渲染英文、简体中文和阿拉伯语，在浏览器检查桌面及 390 像素宽度。将双按钮合并为同一行，窄屏自动换行；阿拉伯语正文增加从右向左阅读方向。发现外部徽章服务会拉散泰语和阿拉伯语字形，改用保留双区域配色的本地 SVG 徽章。窄屏预览没有横向溢出或损坏图片。

核验范围：15 种 Overview 语言、45 个项目语言链接、135 个官网及模型入口。官网链接做 HTTP GET 检查；4 个链接首次返回 200 但下载超时，重试后完整读取。未执行图片或视频生成测试。来源与链接核验数据见本目录的 sources.md 及 data 目录。

## 介绍内容扩写

根据后续反馈，扩写全部 15 种语言的品牌介绍、资料库说明、功能用途、入门步骤与参与方式。文案按“有哪些材料、能学到什么、适合谁”展开，并用香水光影、双人对白、物件交接和旅行日记等已有案例区分三个项目。

子代理对比旧版及项目原文，指出用途标签与人群描述不匹配、项目介绍同质和操作步骤重复。主对话采纳后：调整标签，给各项目补充具体例子，将开源介绍集中到参考画面、提示词文本和原始来源；复核中再统一中文案例名称。最后由主对话检查生成一致性和实际渲染。此次未更换封面、按钮样式或链接目标。
