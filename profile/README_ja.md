## SeaImagine で制作を始める

SeaImagine は、クリエイター、デザイナー、小規模チーム向けのオンライン AI 画像・動画制作プラットフォームです。テキストや参照画像をもとにモデルを試し、場面を調整できます。

## 作例をアレンジして学ぶ

被写体、カメラの動き、タイミング、音の組み合わせを学べるプロンプト集を公開しています。画像付きの作例を見てプロンプトをコピーし、要素を一つずつ変えてみましょう。

## プロンプト集を探す

画像はプロンプト集の表紙です。クリックすると作例と出典を確認できます。

プロンプトの言語は資料集によって異なります。各プロジェクトの説明をご確認ください。

## SeaImagine で作る

| SeaImagine で作る | 用途 |
| --- | --- |
| **[テキストから動画](https://seaimagine.com/ja/text-to-video/)** | 場面を文章で説明して動画にする。 |
| **[画像から動画](https://seaimagine.com/ja/image-to-video/)** | 静止した参照画像に動きを加える。 |
| **[画像生成](https://seaimagine.com/ja/ai-image-generator/)** | 物語や商品に使う画像を作る。 |
| **[写真編集](https://seaimagine.com/ja/ai-photo-editor/)** | 既存の画像を修正・調整する。 |

[![SeaImagine を開く](https://img.shields.io/badge/SeaImagine-SeaImagine%20%E3%82%92%E9%96%8B%E3%81%8F-7c3aed?style=for-the-badge)](https://seaimagine.com/ja/create/)

## 一つの作例から始める

1. 作例を選び、プロンプトをコピーする。
2. SeaImagine でモデルを選び、テキストを入力するか参照画像をアップロードする。
3. 被写体の一貫性、カメラの動き、音を確認し、条件を一つずつ変える。

## 学んだことを共有する

該当リポジトリでの質問、翻訳の改善、プロンプト・設定・出典を添えた作例の投稿を歓迎します。利用前に各リポジトリのライセンスをご確認ください。
