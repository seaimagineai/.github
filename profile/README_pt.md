## Crie com SeaImagine

SeaImagine é uma plataforma online de criação de imagens e vídeos com IA para criadores, designers e pequenas equipes. Comece com texto ou uma imagem de referência, experimente um modelo e refine sua cena.

## Aprenda adaptando exemplos

Compartilhamos bibliotecas de prompts para mostrar como combinar o assunto, os movimentos de câmera, o ritmo e o som. Explore um exemplo ilustrado, copie o prompt e ajuste um elemento por vez.

## Explore as bibliotecas de prompts

As imagens são capas das bibliotecas de prompts. Clique para consultar os exemplos e suas fontes.

Os idiomas dos prompts variam entre as bibliotecas. Consulte a documentação de cada projeto.

## Comece com um exemplo

1. Escolha um exemplo e copie o prompt.
2. Selecione um modelo no SeaImagine e digite um texto ou envie uma imagem de referência.
3. Confira a consistência do assunto, a câmera e o som. Mude uma condição por vez.
