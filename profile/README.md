## Create with SeaImagine

SeaImagine is an online AI image and video creation platform for creators, designers and small teams. Start with text or a reference image, explore a model, and refine your scene.

## Learn by adapting examples

We share prompt libraries so creators can see how subject, camera movement, timing and sound fit together. Browse an illustrated example, copy its prompt, and adapt one element at a time.

## Explore the prompt libraries

These images are prompt library covers. Select one to explore its examples and sources.

Prompt languages vary by library. Check the documentation for each project.

## Start with one example

1. Choose an example and copy its prompt.
2. Select a model on SeaImagine, then enter text or upload a reference image.
3. Check subject consistency, camera movement and sound. Change one condition at a time.

## Share what you learn

Open an issue in the relevant repository, improve a translation, or contribute an example with its prompt, settings and source. Check each repository’s license before using its content.
